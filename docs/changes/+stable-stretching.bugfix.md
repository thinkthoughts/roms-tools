`compute_cs` (the S-coordinate stretching `Cs_r`, `Cs_w`) evaluates its two steps without cancellation (`cosh(x) - 1 = 2 sinh(x/2)**2`, `numpy.expm1`). Against 50-digit values it is now accurate to 7e-16 for every `theta_s`, `theta_b`; it gave NaN for `theta_s <= 1e-8`, lost up to 3e-3 for small `theta_s` and up to 7e-7 for small `theta_b`. For `theta_s >= 0.5` and `theta_b = 0` or `>= 0.1` the values change by at most 8e-15, so grids from earlier versions and output of ucla-roms 0.16.0 still match.
