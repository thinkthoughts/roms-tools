`join_datasets`, `open_partitions` and `join_netcdf` now join tiles whose files hold only rho-point variables correctly: they placed such tiles by a layout guessed from dimension sizes, which is ambiguous when all tiles in a column have the same size (for example a 2-row split of a grid with 2 interior rows), and returned a wrongly assembled dataset.
* `partition` and `partition_netcdf` write ucla-roms' `partition` global attribute `(node, nnodes, xi_start, eta_start)` on every tile, as ucla-roms and its `Tools-Roms/partit.F` do, and the join functions place tiles by it when all files carry it. Files without it are joined as before.
